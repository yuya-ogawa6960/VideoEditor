# App Store 申請の手順（ご自身で行う作業）

申請に使う文章（説明文・キーワード・審査メモ・プライバシーの答え）は `docs/AppStoreSubmission.md` にまとめてあります。この手順書では「どこを押して、何を入れるか」だけを書きます。
画面の名前は、Apple や Google の都合で少し変わることがあります。見つからないときは、近い名前のものを選んでください。

## 全体の順番

| 順番 | 作業 | どこで | 必須 |
|---|---|---|---|
| 1 | 「ビルドして」で 1.12.69 を作る | ここ（Claude） | 必須 |
| 2 | テスト用のアカウント ID を登録 | iPhone と GitHub | 任意 |
| 2-2 | Apple でサインインの鍵を登録 | Apple Developer と GitHub | 必須 |
| 3 | 広告ポイントの確認用 URL を登録 | AdMob | 必須 |
| 4 | アプリの基本情報 | App Store Connect | 必須 |
| 5 | プライバシーの表示 | App Store Connect | 必須 |
| 6 | 年齢制限・価格・配信する国 | App Store Connect | 必須 |

## 1. 1.12.69 を作る

ここで「ビルドして」と送ってください。審査前の修正が入ったビルドが TestFlight に届きます。
審査にはこの 1.12.69（またはそれより新しいビルド）を出します。

## 2. テスト用のアカウント ID を登録（ふつうは不要）

TestFlight 版と審査中のアプリは、Apple が署名した「テスト版で動いている」証明をサーバーに送るので、広告のポイントは自動で付きます。
この手順は、その証明が取れない端末でだけ必要です。やらなくても申請には関係ありません。

**iPhone で ID を調べる**
1. TestFlight から 1.12.69 を入れて開きます。
2. プロジェクト一覧の左上の星のアイコンを押し、「Apple でサインイン」をします（済んでいれば不要）。
3. 一覧に戻り、右上の歯車（設定）を押します。
4. いちばん下の「バージョン」の行を 5 回タップすると、「サポート用の情報」が出るので開きます。
5. 「アカウント ID」の英数字を長押しして、コピーします。

**GitHub に登録する**
1. ブラウザで https://github.com/yuya-ogawa6960/VideoEditor を開きます。
2. 上の「Settings」→ 左の「Secrets and variables」→「Actions」を押します。
3. 緑の「New repository secret」を押します。
4. Name に `TEST_AD_USERS`、Secret にコピーした ID を貼り付けて、「Add secret」を押します。
   - 何人か入れるときは、ID をカンマ（,）で区切ります。
5. 上の「Actions」タブ → 左の「Deploy server」→ 右の「Run workflow」→ もう一度「Run workflow」を押します。
6. 1〜2 分で緑のチェックが付けば終わりです。

## 2-2. Apple でサインインの鍵を登録（アカウント削除のため）

アカウントを削除したとき、Apple 側のサインインも解除するための鍵です。Apple が「サインイン機能のあるアプリはこれを行う」と案内しているので、申請前に済ませます。

**Apple Developer で鍵を作る**
1. https://developer.apple.com/account/resources/authkeys/list を開きます。
2. 「+」を押し、名前に `Video Mania Sign in` と入れます。
3. 「Sign in with Apple」にチェックを入れ、「Configure」で Primary App ID に `com.yuyaogawa6960.videomania` を選び、「Save」→「Continue」→「Register」を押します。
4. 「Download」で `.p8` ファイルをダウンロードします。一度しかダウンロードできないので、なくさないでください。
5. 画面の「Key ID」（10 文字）を控えます。

**GitHub に登録する**
1. https://github.com/yuya-ogawa6960/VideoEditor の「Settings」→「Secrets and variables」→「Actions」を開きます。
2. 「New repository secret」で次の 3 つを作ります。

| Name | Secret |
|---|---|
| `APPLE_SIWA_KEY_ID` | 控えた Key ID |
| `APPLE_SIWA_KEY_P8` | `.p8` ファイルをメモ帳で開いて、中身をすべて貼り付け |
| `APPLE_TEAM_ID` | `779F5Z8KQX` |

3. 「Actions」→「Deploy server」→「Run workflow」で反映します。

## 3. 広告ポイントの確認用 URL を登録（AdMob）

本番の App Store 版で、広告を最後まで見た人にポイントを付けるための設定です。これをしないと、本番では広告を見てもポイントが付きません。

1. https://apps.admob.com を開き、広告に使っている Google アカウントでログインします。
2. 左の「アプリ」→「Video Mania」→「広告ユニット」を押します。
3. 種類が「リワード」の広告ユニットを開きます（ID の最後が `4003023795`）。
4. 「広告ユニットの設定」の中の「サーバーサイド認証」をオンにします。
5. 「コールバック URL」に次を入れます。
   ```
   https://videomania-api.yuya-ogawa0906.workers.dev/v1/ads/ssv
   ```
6. 「URL を確認」を押して、問題がないことを確かめてから「保存」を押します。

**広告の内容の上限も合わせる（年齢 4+ 向け）**
1. 左の「アプリ」→「Video Mania」→「アプリの設定」を開きます。
2. 「広告コンテンツのレーティング」で「G」を選んで保存します。アプリ側でも同じ上限を設定済みですが、管理画面も合わせておきます。

## 4. アプリの基本情報（App Store Connect）

1. https://appstoreconnect.apple.com を開き、「アプリ」→「Video Mania」を押します。
2. 左の「App 情報」を押し、次を入れて右上の「保存」を押します。

| 項目 | 入れるもの |
|---|---|
| サブタイトル | AI で簡単、本格動画編集 |
| カテゴリ | 写真/ビデオ（サブ：エンターテインメント） |
| コンテンツ配信権 | 「はい、含む」→「必要な権利を持っている」（Google Fonts の書体を表示するため。書体は自由に使えるライセンス） |

3. 左の「App のプライバシー」を開き、「プライバシーポリシー URL」に次を入れて保存します。
   ```
   https://videomania-api.yuya-ogawa0906.workers.dev/privacy
   ```

## 5. プライバシーの表示（App のプライバシー）

1. 同じ「App のプライバシー」の画面で「はじめに」（または「編集」）を押します。
2. 「データを収集していますか？」に「はい」と答えます。
3. 次の種類にチェックを入れて「保存」します。

| 種類（画面の名前） | 使い道 | ユーザに関連付け | トラッキング |
|---|---|---|---|
| ユーザ ID | App の機能 | はい | いいえ |
| デバイス ID | サードパーティ広告 | いいえ | はい |
| 広告データ | サードパーティ広告 | いいえ | はい |
| おおよその位置情報 | サードパーティ広告 | いいえ | はい |
| 製品の操作 | サードパーティ広告、アナリティクス | いいえ | いいえ |
| オーディオデータ | App の機能 | いいえ | いいえ |
| その他のユーザコンテンツ | App の機能 | いいえ | いいえ |
| クラッシュデータ | アナリティクス | いいえ | いいえ |
| パフォーマンスデータ | アナリティクス | いいえ | いいえ |
| その他の診断データ | アナリティクス | いいえ | いいえ |

4. 種類ごとに上の表のとおり答え、最後に右上の「公開」を押します。

迷ったときは、次のように考えてください。
- **広告の分。** デバイス ID・広告データ・位置は Google AdMob が集めます。トラッキングは、利用者が許可したときだけ行われます。それでも、ここでは「はい」と答えます。
- **サインインの分。** ユーザ ID は Apple でサインインの識別子です。名前やメールは受け取っていません。
- **AI の分。** オーディオとユーザコンテンツは、クラウド AI を使うときに OpenAI や Google に送る音声と文章です。保存はしません。

## 6. 年齢制限・価格・配信する国

**年齢制限**
1. 左の「App 情報」の「年齢制限」で「編集」を押します。
2. 暴力・成人向け・ギャンブルなどの内容の質問は、すべて「なし」と答えます。
3. 広告についての質問があれば「あり」と答えます。
4. 利用者どうしでやり取りする機能（チャット・投稿の公開）はないので、その質問は「いいえ」です。
5. 結果が 4+（または一番下の年齢）になれば「完了」を押します。

**価格と配信状況**
1. 左の「価格および配信状況」を開きます。
2. 価格は「無料」にします。
3. 配信する国は「すべての国または地域」で問題ありません。日本だけで始めたいときは、日本だけを選びます。
4. 右上の「保存」を押します。

## 7. スクリーンショットと説明文、ビルドを選ぶ

左の上のほうにある「iOS App」の「1.12.69 提出準備中」を押します。表示されていなければ、「iOS App」の横の「+」で `1.12.69` を作ります。番号は、ビルドの番号と同じにします。

**スクリーンショット**
- 必要なのは「6.9 インチ」の枠だけです。小さい画面の分は、Apple が自動で縮めます。
- 1 枚の大きさは 1320×2868（縦）です。Pro Max 以外の iPhone で撮ると大きさが合わないので、撮った画像をここに送ってください。大きさを合わせて返します。
- 3〜6 枚がおすすめです。次の順番で撮ってください。
  1. 編集画面（タイムラインとプレビュー）
  2. キャプションの自動作成とデザイン
  3. おまかせ編集
  4. トランジションの見本
  5. 中だるみチェック
  6. 書き出し画面（完成した動画が出ている所）
- 画像は、枠の中へドラッグするか「ファイルを選択」で入れます。

**文章**（`docs/AppStoreSubmission.md` からコピー）
| 欄 | 中身 |
|---|---|
| 概要（説明文） | 「説明文（日本語）」の部分 |
| キーワード | 「キーワード」の 1 行。カッコの中の注意書きは入れない |
| サポート URL | https://videomania-api.yuya-ogawa0906.workers.dev/support |
| 著作権 | 2026 Yuya Ogawa |

**ビルド**
1. 「ビルド」の欄の「+」を押して、1.12.69 を選びます。
2. 「暗号化」の質問は出ません。アプリ側で「独自の暗号化は使っていない」と申告済みだからです。

**App Review に関する情報**
1. 「サインインが必要です」のチェックは外します。サインインしなくても使えるからです。
2. 連絡先（名前・電話番号・メール）を入れます。
3. 「メモ」に、`docs/AppStoreSubmission.md` の「App Review への情報」の箇条書きを貼り付けます。

右上の「保存」を押します。

## 8. 審査に提出

1. 同じ画面の右上の「審査用に追加」（または「審査へ提出」）を押します。
2. 足りない項目があると赤く表示されます。表示どおりに埋めてから、もう一度押します。
3. 「提出」を押すと、状態が「審査待ち」になります。
4. 審査は、たいてい 1〜2 日で終わります。結果はメールで届きます。
5. 却下されたときは、App Store Connect の「App Review」にあるメッセージを、そのままここに貼ってください。直し方を一緒に考えます。

公開のしかたは、提出の前に「バージョンのリリース」で選べます。「承認後に手動でリリース」にしておくと、公開日を自分で決められます。

## 9. 小規模事業者プログラム（課金を始める前まで）

年間の売上が 100 万ドル以下なら、App Store の手数料が 30% から 15% になります。今はアプリ内課金がないので急ぎませんが、有料プランを始める前に済ませてください。

1. https://developer.apple.com/app-store/small-business-program/ を開きます。
2. 「登録」（Enroll）を押し、Apple Developer のアカウント保有者の Apple ID でログインします。
3. 「関連する開発者アカウント」は、ほかに持っていなければ「なし」と答えます。
4. 内容を確認して提出します。結果はメールで届きます。

有料プランを始めるときは、App Store Connect の「ビジネス」で「有料 App 契約」に同意し、銀行口座と税金の情報を登録します。これは課金を作るときに、あらためて手順をお伝えします。
