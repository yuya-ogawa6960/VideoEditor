Core (OpenCineCore, OpenCineCoreTestSupport, OpenCineMedia, OpenCineFrameIO, OpenCineMotion,
OpenCineRelay, OpenCineApple; Android core, media, vulkan)
----------------------------------------------------------
The contracts are informed by OpenPocketCine, OpenInstaCine and OpenZCine (Apache 2.0,
same authors). No third-party code and no manufacturer SDK or documentation is included.

OpenCineMedia moves media math out of OpenPocketCine and OpenInstaCine (Apache 2.0, same
authors). The `.cube` parser (`CubeLUT`), `FrameRateSampler`, the custom LUT index and the
traffic-light meter are adapted from OpenZCine (Apache 2.0, same authors), as are the merged
CubeLUT and frame-rate tests.

OpenCineFrameIO moves the Frame.io request planning, OAuth PKCE, response models and their
tests from OpenZCine, and the iOS upload client from OpenZCine and OpenPocketCine (Apache 2.0,
same authors). It talks to the public Frame.io Platform API v4 and Adobe IMS; no Adobe SDK or
documentation is included. Frame.io and Adobe are trademarks of Adobe, used for identification
only.

Transfer curve constants are implemented from published specifications: ITU-R BT.709-6,
ITU-R BT.2100 and BT.2408 (HLG); the DJI D-Log / D-Gamut white paper (2017); the D-Log2 white
paper by Gamut (Revision 1.0, 2026-06-30); and the Insta360 10-bit I-Log white paper (June
2026). The D-Log M curve is an empirical neutral-channel fit taken from Thatcher Freeman's
Pocket 3 DCTL (github.com/thatcherfreeman/dwg-transforms, revision 22f2134e); only the
numeric fit is used, no code from that repository. Camera Rec.709 cubes and the grey-axis
curves derived from them stay in each app.

Test fixtures name camera families ("DJI-like", "Nikon-like", "Luna-like") only to describe
the behavior they imitate, and curve names (D-Log, D-Log2, D-Log M, I-Log) identify published
transfer functions. DJI, Nikon, Insta360 and Luna are trademarks of their respective
owners, used for identification only. This project is not affiliated with or endorsed by them.

Multicam (OpenCineMulticam; Android multicam)
---------------------------------------------
The engine generalizes multicam behavior from OpenPocketCine (record confirmation context,
per-tile recovery budget, controls-only editor admission) and OpenZCine (group record plan and
mixed results, multicam eligibility), both Apache 2.0, same authors. No third-party code and no
manufacturer SDK or documentation is included.

Test fixtures from OpenCineCoreTestSupport name camera families ("DJI-like", "Nikon-like",
"Luna-like") only to describe the behavior they imitate. DJI, Nikon, Insta360 and Luna are
trademarks of their respective owners, used for identification only. This project is not
affiliated with or endorsed by them.
