# Team contract (internal, for parallel implementation)

iOS app "VideoEditor": SwiftUI + AVFoundation, deployment target **iOS 18.0**, Swift language mode 5
(NOT strict concurrency), built with the newest Xcode available on GitHub Actions (Xcode 16.x or 26.x — code
must compile on both; guard iOS 26-only APIs with `#if compiler(>=6.2)` AND `if #available(iOS 26.0, *)`).
Project is generated by XcodeGen from `project.yml`; every `.swift` file under `Sources/` is compiled into one
target, so all types are visible to each other without imports of our own modules.

Nobody can compile on this machine (Windows). Write conservative, well-known APIs. Re-read your code for compile
errors: missing `try`/`await`, optional unwrapping, `@MainActor` mistakes, `CMTime` arithmetic, Sendable issues.

## Shared model (already written, DO NOT EDIT): `Sources/Model/Models.swift`
Read it fully first. Key types: `Clip`, `CameraAngle`, `AngleSwitch`, `MulticamInfo`, `FilterSettings`,
`FilterPreset`, `ColorAdjustments`, `SubtitleCue`, `SubtitleStyle`, `AudioSettings`, `CanvasSettings`
(`aspect`, `scaling`, `resolution`, `quality`, `frameRate`), `ProjectSnapshot` (Equatable value copy),
`EditorProject` (@Observable class), `orientedSize(naturalSize:transform:)`.
If you need helpers, put them in your own files (extensions are fine). Never redeclare a type owned by
another team. Prefix private helper types with your file's topic to avoid name clashes.

Timeline semantics: clips play back-to-back in order. A clip uses source range `startTime..<endTime`,
played at `speed` → output length `outputDuration`. `SubtitleCue.start/end` are OUTPUT timeline seconds.
`AngleSwitch.time` is MAIN-clip SOURCE seconds. Angle source time = main source time + `angle.offset`.

## Team A — Composition engine
Files (only these): `Sources/Engine/CompositionBuilder.swift`, `Sources/Engine/VideoCompositor.swift`,
`Sources/Engine/FilterEngine.swift`, `Sources/Engine/SubtitleRenderer.swift`

```swift
enum RenderPurpose { case preview, export }

struct BuiltComposition {
    let composition: AVComposition
    let videoComposition: AVVideoComposition
    let audioMix: AVAudioMix?
    let renderSize: CGSize
    let duration: CMTime
}

enum CompositionBuilder {
    /// Output pixel size (even integers). export: short side = canvas.resolution.maxShortSide;
    /// preview: short side = min(that, 720). Aspect = canvas.aspect.ratio, or for .original the first clip's
    /// displaySize ratio (9:16 if there are no clips).
    static func renderSize(for snapshot: ProjectSnapshot, purpose: RenderPurpose) -> CGSize
    static func build(_ snapshot: ProjectSnapshot, purpose: RenderPurpose) async throws -> BuiltComposition
}

enum FilterEngine {
    static func apply(_ settings: FilterSettings, to image: CIImage) -> CIImage
    /// For UI filter picker thumbnails
    static func preview(_ image: UIImage, settings: FilterSettings) -> UIImage?
}

enum SubtitleRenderer {
    /// Image already positioned inside a canvas of renderSize (CoreImage coords, origin bottom-left).
    /// Must be cached (same cue text/style/size → same CIImage). Thread-safe.
    static func image(lines: [String], style: SubtitleStyle, renderSize: CGSize) -> CIImage?
}
```
Requirements:
- Use a custom `AVVideoCompositing` class (+ custom `AVVideoCompositionInstructionProtocol`) so preview
  (AVPlayerItem) and export render identically: per-frame pick source track (main or multicam angle), apply
  preferredTransform + canvas scaling (`.fit` black bars, `.fitBlur` blurred enlarged copy behind,
  `.fill` center crop), clip `FilterSettings`, then subtitles active at that output time
  (`cue.displayLines(mode: style.displayMode)`).
- CIContext: GPU normally. If `AppLifecycle.shared.isInBackground` is true (Team B owns it; thread-safe Bool),
  render with a CPU context (`CIContext(options: [.useSoftwareRenderer: true])`) because the GPU is unavailable
  to background apps. Create both contexts lazily once.
- Composition: main video track(s) + one extra composition track per angle segment as needed (alternate
  tracks A/B are fine). Speed via `scaleTimeRange`. Clips with no video track → skip. Multicam angle missing
  frames (outside its duration) → fall back to main.
- Audio: each clip's own audio (unless `isMuted` or `!hasAudio`) at `audio.originalVolume`; for multicam
  always the MAIN clip audio. BGM (`audio.bgmURL`) looped to total duration at `bgmVolume`, with a 2 s
  fade-out at the end when `bgmFadeOut`. Return an `AVMutableAudioMix`.
- Frame duration from `canvas.frameRate`. Pixel format kCVPixelFormatType_32BGRA for source and output.

```swift
final class AppLifecycle {

@Observable final class ExportManager {

```
Requirements:
- Player item: `audioTimePitchAlgorithm = .spectral`, apply built videoComposition + audioMix; periodic time
  observer updates currentTime; loop not required.
- Export pipeline: AVAssetReader (AVAssetReaderVideoCompositionOutput + AVAssetReaderAudioMixOutput with
  `.spectral`) → AVAssetWriter (H.264, HEVC when the short side ≥ 2160; bitrate from StorageEstimator;
  AAC 48 kHz stereo 192 kbps), `.mp4` in a temp/Documents "Exports" folder. Progress from presentation time.
- Before starting: StorageEstimator check; if insufficient → `.failed("空き容量が不足しています ...")`.
- Background: start a `UIApplication.beginBackgroundTask`; additionally on iOS 26 (`#if compiler(>=6.2)` +
  `#available(iOS 26.0, *)`) submit a `BGContinuedProcessingTaskRequest` with identifier
  `com.personal.videoeditor.export` (registered once at launch via `BGTaskScheduler.shared.register` in
  `AppLifecycle.start()`), report progress to it, and complete it at the end. Expiration → cancel cleanly.
- Request notification permission at first export; post a local notification when export finishes while in
  background.
- Optionally save to Photos (PHPhotoLibrary, add-only authorization).

## Team C — Transcription, translation, multicam auto-sync
Files: `Sources/Engine/TranscriptionService.swift`, `Sources/Engine/TranslationSupport.swift`,
`Sources/Engine/AudioSync.swift`

```swift
enum TranscriptionLanguage: String, CaseIterable, Identifiable {
    case japanese = "ja-JP", english = "en-US"
    var id: String { get }; var displayName: String { get }; var locale: Locale { get }
}
@Observable final class TranscriptionService {
    private(set) var isRunning: Bool
    private(set) var progress: Double
    private(set) var statusText: String
    func requestAuthorization() async -> Bool
    /// Returns cues in OUTPUT timeline seconds (accounts for trim + speed + clip order). Skips muted clips.
    func transcribe(snapshot: ProjectSnapshot, language: TranscriptionLanguage) async throws -> [SubtitleCue]
    func cancel()
}

struct TranslationRequest: Equatable { let id: UUID; let source: TranscriptionLanguage; let targetIsEnglish: Bool }
extension View {
    /// Attach once (Team E uses it). When `request` becomes non-nil, translates every
    /// `project.subtitles[i].text` into `translatedText` using Apple's Translation framework
    /// (`.translationTask` + `TranslationSession.translations(from:)`), then sets `request = nil`
    /// and calls onFinish. Must run on device only (no network keys).
    func subtitleTranslation(project: EditorProject, request: Binding<TranslationRequest?>,
                             onFinish: @escaping (Result<Int, Error>) -> Void) -> some View
}

enum AudioSync {
    /// Offset such that angleTime = mainTime + offset, via audio envelope cross-correlation (Accelerate/vDSP),
    /// search window ±maxOffset seconds. Throws if either file has no audio.
    static func estimateOffset(mainURL: URL, angleURL: URL, maxOffset: Double = 60) async throws -> Double
}
```
Requirements: transcription with `SFSpeechRecognizer` on-device when supported
(`requiresOnDeviceRecognition`), audio extracted per clip trim range to temp `.m4a` (or PCM) and processed in
chunks of ≤ 50 s; build cues from `SFTranscriptionSegment` timestamps, grouping words into cues of ≤ ~3.5 s
or ~20 Japanese chars / 8 English words. Map source time → timeline time (÷ speed + clip start). Works for long
videos (iterate chunks, report progress, cancellable).
